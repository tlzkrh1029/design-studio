# night_xml — 밤의 가판대 다듬기 (specs/night.xml)

<plan>
1. 구역 순서(메뉴와 1:1, 5개): 상단 막대(--topbar-height, 고정) → 오늘의 호(히어로) → 가판대 → 국면·지표 → 발행 목록 → 안내(갱신 방식·부속 문서·바닥글 링크). 본문 폭 --content-width = 1440 − 2×--gutter, 구역 사이 --section-gap, 머리와 내용 사이 --section-head-gap, 모든 구역 머리는 같은 꼴(굵은 제목 + 작은 보조 이름 + 오른쪽 회색 설명 + 머리카락선).
2. 히어로 격자: --hero-stage-width 560 | --hero-col-gap 80 | --hero-text-width 640 = 1280. 위 여백 --hero-pad-top, 표지 --cover-hero 440(높이 약 647) + 받침 → 표지 바닥 약 y 781로 --viewport-check-height 900 안. 오른쪽 글: 눈썹 줄 → 날짜·호수·실행 한 줄(--fs-hero-date) → 헤드라인(--fs-hero-headline, 가장 큰 글자, --text-1 한 색) → 국면 칸 --phase-cell-hero + 이름 + 보조 줄(임시 기준·전날 비교) → 지표 세 칸(세로 머리카락선, 오늘 값 + 기준선 대비 한 줄) → '브리핑 펼치기'(채움) + '지난 호 넘겨 보기'(테두리).
3. 가판대 격자: 월요일 시작 주 단위 선반 5줄(09.28 주 → 09.02 주), 표지 --cover-shelf 140, 날 사이 --gap-day, 같은 날 회차 사이 --gap-same-day, 선반 사이 --shelf-row-gap, 선반과 꼬리표 사이 --tag-gap. 가장 넓은 줄(09.21 주, 8장) 8×140+6×20+8 = 1248 ≤ 1280. 선반 판은 화면 폭 전체, 줄마다 --light-shelf 띠 조명 + 주 범위 꼬리표. 꼬리표는 날짜·요일만(국면 없음).
4. 흐름 격자: --flow-label-width 176 + 30열(09.02~10.01) × --flow-day-width 36 + 월요일 4번 × --flow-week-gap 6 = 1280. 국면 칸 줄(--flow-cell-height), 날짜 축, 지표 세 줄(--flow-track-height, 사이 --flow-track-gap)이 같은 x 함수 하나를 쓴다. 눈금은 줄마다 2~3개, +1.0%p와 0 기준선은 --line-ref 점선 + 이름.
5. 상태: 브리핑 없는 날(09.18·19) — 가판대 --slot-empty-border 빈 자리 + 꼬리표 '브리핑 없음', 흐름 점선 칸 + 지표 선 끊김, 목록은 두 날을 한 줄로.
6. 상태: 다음 호(10.01 목 06:10) — 맨 위 선반 오른쪽 끝 --slot-next-border 자리 + --accent-glow, 흐름 축 끝 강조색 점선 칸. 안에는 '다음 호'와 날짜·시각만. 여러 번 낸 날(09.03·09.05·09.24) — 표지를 --gap-same-day로 붙이고 꼬리표 하나('09.03 목 · 3회') + 표지별 회차 번호, 흐름 칸은 마지막 회차 국면 + 회차 수만큼 점, 목록은 회차별 행(날짜는 첫 행에만).
7. 상태: 값 없음 — 국면 없음 '?' 칸(--phase-none), 걸친 판정은 두 국면 색 반반, 헤드라인 없음은 note를 --text-2 + '메모', 지표 없음 '—' + 선 끊김, 전날 국면 없으면 그 줄 생략. 검색 결과 없음 — 목록 자리에 "‘검색어’에 맞는 호가 없습니다." + '범위를 전체로'·'검색 지우기' + 예(09.24), 다른 구역은 그대로.
8. 강조색(--accent)은 히어로 빛, '브리핑 펼치기', 오늘 표식(선반 꼬리표·흐름 칸 테두리·차트 오늘 점), 다음 호 자리, 초점 테두리·검색어 강조에만. 증감은 부호와 ▲▼를 --text-2로.
</plan>
