# library_night: 서고 7번째 판(밤의 가판대)

1차 실험의 밤의 가판대 YAML 결과를 실제 서고에 옮긴 판입니다. 옮긴 내용과 확인 과정은 [docs/07_서고_적용_이력.md](../../docs/07_서고_적용_이력.md)에 있습니다.

| 파일 | 내용 |
| --- | --- |
| `src.html` | 원본. `/*<<MZCSS>>*/`, `/*<<MZJS>>*/` 자리에 표지 모듈이 들어갑니다. |
| `build.py` | `final.html`(게시본)과 `preview.html`(로컬 미리보기)을 만듭니다. |
| `final.html` | 2026년 10월 1일 12시 29분에 게시한 7번째 판 |
| `preview.html` | 로컬 글꼴, 데이터 사본, 가짜 `window.claude`, 고정 시계(10월 1일 12:30)를 쓰는 미리보기 |
| `shot.py` | 여러 폭으로 캡처하고 가로 넘침, 표제 넘침, 오류를 출력합니다. |
| `db_snapshot.json`, `db/` | 게시 직전에 읽은 서고 데이터베이스 사본(브리핑 32건, 부속 문서 1건) |
| `screenshots/` | 1440, 1300, 820, 390px 확인 캡처와 YAML 시안 비교 이미지 |
