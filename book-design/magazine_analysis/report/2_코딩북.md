# 코딩북

표지 1장마다 아래 55개 범주형 항목을 기록하고, 13개 계량 지표를 계산했습니다. 범주는 서로 겹치지 않도록 정의했고, 한 표지에 여러 값이 해당하면 가장 두드러진 값 하나를 고릅니다.

판정 기준은 다음과 같습니다.

- 보조 커버라인은 줄이 아니라 기사 단위로 셉니다.
- 표제 글자 높이는 메인 표제에서 가장 큰 글자의 높이를 표지 전체 높이와 비교합니다.
- 이미지 점유 면적은 배경을 뺀 주 이미지(인물, 오브젝트, 장면)가 차지하는 면적입니다. 배경까지 하나의 장면이면 풀블리드로 봅니다.
- 가장 먼저 보이는 요소는 표지를 1초 동안 봤을 때 시선이 처음 가는 요소입니다.
- 톤과 무드는 1~5점 척도로, 3점이 중간입니다.
- 계량 지표는 한경비즈니스의 흰 여백과 매경이코노미의 주황 테두리를 뺀 영역에서 계산했습니다. 테두리는 모든 호에 똑같이 들어가는 고정 요소여서, 호별 차이를 비교할 때 방해가 되기 때문입니다.

## 세부 판정 규칙

- **부제**: 표제 블록 안에서 크기·굵기·색이 뚜렷이 다르고, 본표제를 설명하는 별도 구절(킥커나 덱)이 있을 때만 '있음'으로 봅니다. 한 구절을 이어서 완성하는 줄은 부제가 아닙니다.
- **퍼프·배지**: 인증 마크, 스티커, 사선 띠, 특집 로고, 별책 표지, 'OO 선정' 라벨처럼 내용을 홍보하는 그래픽 장치입니다. 보조 커버라인 앞의 작은 '단독' 표시는 넣지 않습니다.
- **제호와 이미지의 겹침**: 이미지의 일부가 제호 글자 앞을 지나가면 '가림', 하늘이나 단색이 아닌 이미지의 세부가 제호 바로 뒤에 깔리면 '얹힘'입니다.
- **제작 방식**: 실사 사진은 손대지 않은 듯한 사진, 사진 합성은 사진을 오려 붙이거나 합친 것(인물 누끼 포함), 사실적 3D·CG는 사진처럼 보이는 디지털 렌더링 이미지(생성형 이미지로 보이는 것 포함), 2D 일러스트는 평면·벡터·선 그림, 콜라주·페이퍼는 오린 종이나 찢은 종이 질감입니다.
- **인물 표현**: 실존 인물의 사진은 '실존 인물 사진', 익명 모델의 사진은 '익명 인물 사진', 그리거나 렌더링하거나 실루엣·미니어처로 표현한 인물(실존 인물 포함)은 '그림·실루엣·미니어처'입니다.
