## analysis/: 코딩과 계산

| 파일 | 내용 |
| --- | --- |
| `codebook.json` | 코딩북: 대분류, 항목, 허용 값 |
| `codebook_table.md` | 코딩북을 표로 정리한 초안 |
| `codebook_tab_content.json` | 문서의 코딩북 탭에 처음 넣은 원고(이후 문서에서 고쳐졌으므로 최신본은 `report/2_코딩북.md`) |
| `coding_rules.md` | 판정 규칙(경계 사례를 어떻게 판정하는지) |
| `coding.jsonl` | 최종 코딩 결과(표지 75장, 한 줄에 한 장) |
| `coding_before_audit.jsonl` | 독립 검증으로 고치기 전의 코딩 결과 |
| `audit_changes.json` | 독립 검증에서 고친 항목 목록(표지, 항목, 바꾸기 전 값, 바꾼 값) |
| `coder2_A.jsonl`, `coder2_B.jsonl` | 두 번째 코더 2명이 각각 10장씩 코딩한 결과 |
| `reliability_keys.json` | 일치도 확인에 쓴 표지 20장의 키 |
| `reliability.csv` | 항목별 일치율, 코헨의 카파, 가중 카파, 수준 |
| `rel_md.json` | 일치도 표를 문서에 넣으려고 만든 Markdown |
| `metrics.py` | 계량 지표 계산 스크립트(명도, 채도, 색채감, 대비, 윤곽선, 압축 복잡도, 평탄 영역, 대표색 등) |
| `metrics.csv` | 표지별 계량 지표 |
| `palettes.json`, `palette_rows.json`, `palette_js.txt` | 표지별 대표색 5가지와, 그것을 차트에 넣으려고 바꾼 형식 |
| `combined.csv` | 코딩과 지표를 합친 표(최종본은 `out/주간지_표지_코딩_2026.csv`) |
| `cramers_v.csv`, `assoc_corrected.csv` | 범주형 항목별 카이제곱 검정, 크래머의 V, 보정한 V, BH 보정 q값 |
| `assoc_rows_js.txt`, `assoc_widget_code.txt`, `assoc_widget_code_v2.txt` | 연관도 차트를 문서에 넣을 때 쓴 데이터와 차트 코드 |
| `numeric_tests.csv` | 순서형·수치 항목의 잡지별 중앙값, 사분위수, 맨-휘트니 검정 |
| `freq.txt` | 항목별 잡지별 빈도표 |
| `doc_main_tab.md`, `doc_main_tab_v2.md` | 보고서 본문을 검증할 때 내보낸 중간본(작성자 표시만 지웠습니다) |
| `appendix.md`, `appendix.json`, `appendix_escaped.txt` | 표지별 코딩 탭의 원고와, 문서에 넣으려고 바꾼 형식 |
| `add.py` | 코딩 결과를 코딩북의 허용 값과 대조하며 `coding.jsonl`에 추가하는 스크립트 |
| `out/주간지_표지_코딩_2026.csv` | 최종 결과: 표지 75장 × 55개 항목과 13개 지표 |
| `out/metrics.csv`, `out/palette.csv` | 최종 지표와 대표색 |

## scripts/: 하위 에이전트가 남긴 보조 스크립트

작업 공간의 임시 폴더에 있던 스크립트입니다. 저장 시각으로 보아 앞의 묶음은 두 번째 코더가, 뒤의 묶음은 독립 검증자가 쓴 것입니다.

| 시각 | 파일 | 용도 |
| --- | --- | --- |
| 19:07~19:33 | `stats.py`, `stroke.py`, `shadow.py`, `glyphs.py`, `sw.py` | 표지 이미지에서 명도 통계, 획 굵기, 그림자 효과, 글자 높이를 재는 도구 |
| 19:30~19:33 | `write_codes.py`, `write_b.py` | 두 번째 코더 A조와 B조가 코딩 결과를 JSON Lines로 쓴 스크립트 |
| 20:18~20:29 | `prep.py`, `load.py`, `crop.py`, `sheet.py` | 표지 불러오기, 코딩 데이터 불러오기, 부분 확대, 견본 시트 만들기 |
| 20:24~20:29 | `rel.py`, `rel2.py`, `pal.py`, `pal2.py`, `area.py` | 일치도 다시 계산, 대표색 분류 확인, 이미지 점유 면적 확인 |
