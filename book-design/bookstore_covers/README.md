# bookstore_covers: 서점 베스트셀러 표지 수집 기록

2026년 9월 30일에 알라딘, 예스24, 교보문고의 주간 베스트셀러 150권 표지(앞표지 150장, 뒷표지 109장, 책등 117장)를 모은 작업의 기록입니다. 수집 범위와 방법은 [docs/01_서점_베스트셀러_표지.md](../docs/01_서점_베스트셀러_표지.md)에 있습니다.

| 파일 | 내용 |
| --- | --- |
| `도서목록.csv` | 서점, 목록, 순위, 제목, 저자, 출판사, ISBN, 상품 페이지, 표지 파일 이름(150행) |
| `압축파일_목록.tsv` | 원래 압축 파일 `책표지_베스트셀러_20260930.zip`(188MB)에 들어 있던 파일의 경로와 크기 |

표지 이미지는 각 출판사와 디자이너에게 권리가 있으므로 이 공개 저장소에는 넣지 않았습니다.
