# AGENTS.md: 작업 지침

이 저장소에서 일하는 AI 에이전트(ChatGPT, Codex 등)와 사람이 지킬 규칙입니다. 지금 상태와 남은 일은 [HANDOFF.md](HANDOFF.md)에 있습니다.

## 언어와 문체

- 문서, 화면 문구, 사용자에게 하는 답은 한국어로 씁니다.
- 한국어 문장은 사용자의 '한국어 문체 지침'을 따릅니다. 이 지침은 요약하면 예시가 빠져 뜻이 흐려지므로, 사용자가 프로젝트 지침이나 대화에 넣어 주는 원문을 그대로 적용합니다.
- 코드, 코드 주석, 커밋 메시지, 로그 문자열은 기존 관례를 따릅니다. 이 저장소의 코드 주석과 커밋 메시지는 영어로 되어 있습니다.
- 화면에 영문 장식 라벨(예: ALL ISSUES, INDEX)을 쓰지 않습니다. 지표 이름(BTC.D, ΣSTABLECOIN.D, BTCUSD)과 국면 이름은 데이터에 있는 그대로 씁니다.

## 데이터

- 데이터에 없는 사실이나 값(독자 수, 가격, 일정 등)을 지어내지 않습니다. 값이 없으면 숨기거나 '–'로 둡니다.
- 브리핑 기록(`briefs`)의 필드는 `date`, `seq`(그날 회차), `title`, `url`, `phase`, `prevPhase`, `provisional`, `headline`, `btcd`, `stableD`, `stable1m`, `btc1m`, `lite`, `window`, `run`, `note`, `publishedAt`, `registeredAt`, `registeredBy`입니다. 기록 id는 `YYYY-MM-DD-회차`입니다.
- 국면은 다섯 가지입니다: A 'BTC!' `#CB8242`, B '알트시즌?' `#A96CAF`, C '선별적' `#056F15`, D 'STICKY BTC.D' `#594D99`, E '튀어?' `#2B97FF`. 'C→D'처럼 걸친 판정은 두 색을 반씩 씁니다.
- 첫 호는 2026-09-02입니다. 9월 1일은 서고가 시작되기 전이므로 '브리핑 없는 날'로 세지 않습니다. 9월의 브리핑 없는 날은 9/18, 9/19입니다.
- 기준선은 ΣSTABLECOIN.D 1개월 변화 +1.0%p(E 판정의 임시 기준)와 BTCUSD 1개월 변화 0(D·E 판정의 전제)입니다.
- 음수 부호는 U+2212(−)를 씁니다. 값이 전날과 같으면 '±0.00' 대신 '전날과 같음'처럼 씁니다.

## 표지

- 표지 모듈(`mz.js`)이 그린 표지는 고정 부품입니다. 표지 안쪽(`.mz`와 그 자식)을 고치지 않고, 테두리, 필터, 기울임, 겹쳐 가리기를 하지 않습니다. 표지를 감싼 요소의 그림자, 받침, 링크는 괜찮습니다.
- 표지 비율은 68:100이고, 폭 96~520px에서 그릴 수 있습니다.
- 표지를 페이지에 넣은 뒤, 글꼴을 불러온 뒤, 접힌 구역을 펼친 뒤에는 `BK.fit()`을 불러 표제 크기를 맞춥니다.
- 표지 모듈을 고칠 때는 `cover_design/parts/*.js`를 고치고 `build_mz.sh`로 `mz.js`를 다시 만듭니다. `mz.js`를 직접 고치지 않습니다.
- 배치 계획(`BK.plan`)은 과거 호만 보고 정하므로 새 호가 생겨도 지난 표지는 바뀌지 않아야 합니다. 그림이나 배색 규칙을 바꾸면 지난 표지가 달라지는지 확인하고, 달라지면 사용자에게 알립니다.

## 서고 페이지

- 원본은 `cover_design/library_night/src.html`입니다. `final.html`과 `preview.html`은 `build.py`가 만드는 결과물이므로 직접 고치지 않습니다.
- `window.claude`(데이터베이스, 내려받기)는 Claude 아티팩트 전용 런타임입니다. 로컬에서는 `preview.html`에 들어 있는 가짜 런타임으로 확인합니다.
- 화면 폭 대응을 유지합니다: 1440px 이상은 고정 배치, 1280~1439px는 CSS `zoom`, 1280px 미만은 좁은 배치(YAML 명세의 390px 규칙), 700px 미만은 좌우 여백 16px.
- 실제 기능(데이터베이스 구독, CSV 내려받기, 부속 문서, 알림 문구, 실제 링크, 검색, 펼치기)을 지우지 않습니다.
- 구역 순서와 열 구성은 사용자가 고른 배치입니다. 바꾸려면 먼저 사용자에게 묻습니다.
- 본문 글자는 바탕과 명암비 4.5:1 이상, 24px 이상의 큰 글자는 3:1 이상이어야 합니다.
- 글꼴은 Gothic A1, Outfit, Oswald, IBM Plex Mono, Noto Serif KR, Bodoni Moda 안에서 고릅니다. 사진, 외부 이미지는 쓰지 않고 아이콘은 선 SVG로 그립니다.

## 확인

- 바꾼 뒤에는 `preview.html`을 1440, 1300, 820, 390px 폭으로 렌더링해 가로 넘침(`scrollWidth`), 표지 표제 넘침, 콘솔 오류를 확인합니다(`library_night/shot.py`).
- 렌더링한 화면을 직접 보고 겹침, 잘림, 어색한 빈 자리를 확인합니다.
- 디자인을 바꿨다면 사용자에게 바꾸기 전후 화면을 함께 보여 줍니다.

## 디자인 개선 절차

이 저장소의 목적은 디자인을 단계적으로 개선하는 것이므로, 한 번의 개선을 다음 순서로 진행하고 기록합니다.

1. **기준선 확인**: 지금 실제 서고(7번째 판, `cover_design/library_night/`)가 기준선입니다. 같은 배치인 1차 실험의 YAML 결과는 2차 실험의 블라인드 평가에서 종합 평균 8.0점, 평균 순위 2.33을 받았습니다([docs/06](docs/06_명세_형식_실험_2차.md)).
2. **가설 적기**: 무엇을 왜 바꾸는지 한두 문장으로 먼저 적습니다. 한 번에 한 가지 가설만 다룹니다.
3. **만들기**: 원본을 바로 고치지 않고 `iterations/<YYYY-MM-DD>_<이름>/`에 사본을 만들어 작업합니다. 표지 모듈과 데이터 사본(`db_snapshot.json`)은 바꾸지 않습니다. 그래야 판끼리 같은 조건에서 비교할 수 있습니다.
4. **확인**: 위 '확인' 절의 렌더링 점검을 통과시킵니다.
5. **평가**: 2차 실험과 같은 방식의 블라인드 평가를 씁니다.
   - 평가자는 만든 방식을 모르는 별도의 AI나 사람이고, 기준선과 새 판을 무작위 이름(P1, P2 …)으로 받습니다.
   - 채점 항목은 콘셉트, 첫 화면과 위계, 표지, 다섯 가지 일, 가독성, 완성도(각 1~10점)와 종합 점수, 순위, 페이지마다 강점과 문제 한 줄입니다.
   - 평가 지시문 원문은 `agents/32`~`37`에, 평가용 브리프는 `cover_design/judge/<테마>_<A,B>/brief.md`에 있습니다.
   - 평가자가 실제 데이터를 지어낸 값으로 오해한 적이 있으므로(편집국 1면의 실행 시각), 감점 이유는 데이터와 대조해 확인합니다.
6. **사용자에게 보이기**: 기준선과 새 판의 화면, 점수, 바꾼 점을 함께 보여 주고 사용자가 고르게 합니다. 평가 순위와 사용자의 선택은 다를 수 있으며, 결정은 사용자가 합니다.
7. **기록**: 판 폴더의 `notes.md`에 가설, 바꾼 점, 확인 결과, 점수, 사용자 결정을 적고, `docs/00_작업_일지.md`에 한 줄 요약을 더합니다. 사용자가 채택한 판만 `library_night/src.html`에 반영합니다.

## 저장소

- 공개 저장소입니다. 서점 도서 표지, 잡지 표지처럼 권리가 다른 곳에 있는 이미지를 올리지 않습니다. 목록, 출처 주소, 분석 결과 같은 사실 정보는 올려도 됩니다.
- 사용자의 이름, 이메일 같은 개인 정보를 넣지 않습니다.
- 큰 PNG 화면 캡처는 JPEG로 바꿔 올립니다.
- 스크립트 안의 절대 경로(`/home/claude/cover_design`, `/home/claude/covers`)는 작업 기록이므로 그대로 둡니다. 다른 환경에서는 같은 경로로 심볼릭 링크를 만들거나 실행할 때만 경로를 바꿉니다.
- 글꼴 패키지는 `cover_design/`에서 `npm install`로 받습니다(`node_modules`는 저장소에 없습니다). 캡처에는 Python Playwright와 Chromium이 필요합니다.

## 일하는 방식

- 게시, 공개 저장소에 올리기, 삭제처럼 되돌리기 어려운 일은 먼저 사용자에게 묻습니다.
- 추천이 실험이나 확인으로 뒷받침되지 않았다면 그 사실을 그대로 말합니다.
- 매일 브리핑을 발행하는 예약 작업과 실제 서고 운영은 Claude가 맡습니다. 이어받는 쪽은 디자인 작업에만 집중합니다.
