# 인계 문서: 크립토 브리핑 서고 디자인 작업

이 문서는 Claude와 진행한 디자인 작업을 다른 AI(ChatGPT 등)나 사람이 이어받을 때 가장 먼저 읽는 문서입니다. 기준 시각은 2026년 10월 2일 0시(한국 시간)입니다. 일하면서 지킬 규칙과 디자인 개선 절차는 [AGENTS.md](AGENTS.md)에 따로 두었습니다.

## 0. 이 저장소의 목적

지금까지의 디자인 작업과 그 과정에서 내린 판단을 다른 AI에게 넘겨, 디자인을 배우고 결과를 점점 더 나은 수준으로 개선하게 하는 것이 목적입니다. 매일 브리핑을 발행하는 예약 작업과 실제 서고 운영은 계속 Claude가 맡으므로, 이어받는 쪽은 그 일을 하지 않고 디자인에만 집중합니다.

이어받는 쪽이 할 일은 두 가지입니다.

- 표지와 서고 페이지의 디자인을 개선합니다.
- 개선할 때마다 무엇을 왜 바꿨는지, 어떻게 평가했는지, 사용자가 무엇을 골랐는지 기록해서 다음 작업자가 배울 수 있게 합니다. 절차는 AGENTS.md의 '디자인 개선 절차'에 있습니다.

디자인 작업에 주는 영향은 다음과 같습니다.

- 데이터 사본(`library_night/db_snapshot.json`, 브리핑 32건, 10월 1일 기준)은 고정된 평가용 데이터로 씁니다. 같은 데이터로 만들어야 판끼리 비교할 수 있습니다.
- 사용자가 채택한 디자인을 실제 서고에 게시하는 일은 사용자가 Claude에서 합니다.

## 5. 지금까지의 결정과 이유

1. **표지**: 브리핑 한 편을 잡지 한 호로 봅니다. 틀(테두리, 제호, 커버라인 3줄, 하단 띠)은 모든 호에서 같고, 색과 그림만 호마다 바뀝니다. 주간지 분석에서 매경이코노미의 고정된 틀과 은유 그림, 한경비즈니스의 표제 위계와 색 사용을 참고했습니다.
2. **표지는 고정 부품**: 페이지에서 표지를 다시 꾸미지 않습니다(자세한 규칙은 AGENTS.md).
3. **테마**: 밤의 가판대입니다. 사용자가 구역 순서, 열 구성, 크기를 지정해서 골랐으므로, 이것들을 바꾸려면 먼저 사용자에게 묻습니다.
4. **강조색**: 최신 호 표지의 테두리 색을 쓰고, `#1A1F26`과의 명암비가 4.5:1이 될 때까지 밝힙니다. 그래서 강조색은 날마다 바뀝니다.
5. **실험 결론**: 블라인드 평가의 평균 순위는 명세 없이 1.83, YAML 2.33, 브리프+토큰 3.50, JSON 3.67, XML 태그 3.67, 원래 시안 6.00이었습니다. 형식 사이에 일관된 승자는 없었고, Claude가 앞서 추천한 브리프+토큰 방식이 더 안정적이라는 예상은 확인되지 않았습니다. 형식보다 원래 화면을 직접 보는지, 의도와 이유가 전달되는지가 결과를 더 크게 좌우한 것으로 보입니다([docs/08](docs/08_프롬프트_작성_안내.md)).
