# 2. 경제주간지 표지 디자인 분석

2026년 9월 30일 저녁에 매경이코노미와 한경비즈니스의 2026년 표지 75장을 디자인 관점에서 분석했습니다. 분석 결과는 Claude 문서 「2026 경제주간지 표지 디자인 분석: 매경이코노미·한경비즈니스 75장」으로 정리했고, 이 문서의 세 탭을 모두 이 저장소에 옮겼습니다.

- 보고서 본문: [magazine_analysis/report/1_본문.md](../magazine_analysis/report/1_본문.md)
- 코딩북: [magazine_analysis/report/2_코딩북.md](../magazine_analysis/report/2_코딩북.md)
- 표지별 코딩: [magazine_analysis/report/3_표지별_코딩.md](../magazine_analysis/report/3_표지별_코딩.md)

## 분석 대상

| 항목 | 매경이코노미 | 한경비즈니스 |
| --- | --- | --- |
| 표지 수 | 38장(제2341~2378호) | 37장(제1571~1609호, 합본호 2장 포함) |
| 발행일 | 2026-01-01 ~ 2026-09-30, 매주 수요일 | 2026-01-05 ~ 2026-09-21, 매주 월요일(웹사이트 게시일 기준) |
| 이미지 | 1000×1366px, 주황 테두리 포함 | 2230×2816px, 둘레에 흰 여백 약 120px |

표지 모음은 사용자가 첨부한 `주간지_표지_2026.zip`이었고, 두 잡지의 공식 웹사이트에서 9월 30일에 모은 것입니다. 표지마다 출처 페이지, 원본 이미지 주소, 해시값이 [`magazine_analysis/주간지_표지_2026/표지_목록.json`](../magazine_analysis/주간지_표지_2026/표지_목록.json)에 있습니다.

## 분석 방법

디자인 분석에는 하나로 정해진 국제 표준이 없으므로, 학계와 실무에서 쓰는 틀을 묶어 기술, 분석, 해석의 3단계로 적용했습니다.

| 단계 | 쓴 분석 틀 |
| --- | --- |
| 기술 | 시각 내용 분석(Parry), 잡지 표지 구성 관습, 계량 지표(색채감, 윤곽선 밀도, 압축 복잡도) |
| 분석 | 시각 문법(Kress & van Leeuwen), 게슈탈트 원리, 이텐의 7가지 색채 대비, 서체 분류 |
| 해석 | 바르트의 이미지 수사(정박과 중계), 시각 수사 유형(Phillips & McQuarrie), 파노프스키의 3단계 |

작업은 다음 순서로 진행했습니다.

1. **코딩북 확정**: 75장을 먼저 훑어보고 시범 코딩으로 범주를 다듬은 뒤, 11개 대분류 68개 항목의 코딩북을 확정했습니다. 55개는 범주형 항목이고 13개는 계산하는 지표입니다(`analysis/codebook.json`, `analysis/coding_rules.md`).
2. **계량 지표 계산**: Python으로 평균 명도와 채도, 색채감(Hasler & Süsstrunk), RMS 명도 대비, 윤곽선 밀도(Canny), JPEG 압축 복잡도, 평탄 영역 비율, 대표색 5가지(Lab k-평균) 등을 계산했습니다. 한경비즈니스는 흰 여백을, 매경이코노미는 주황 테두리를 빼고 계산했습니다(`analysis/metrics.py`).
3. **범주형 코딩**: Claude가 표지를 한 장씩 확대해 보면서 55개 항목을 기록했습니다(`analysis/coding.jsonl`).
4. **코더 간 일치도**: 무작위로 고른 20장(잡지별 10장)을 하위 에이전트 2개가 두 번째 코더로서 같은 코딩북으로 다시 코딩했습니다. 자유 기록 항목을 뺀 52개 항목의 평균 일치율은 82%, 코헨의 카파 중앙값은 0.76이었습니다. 카파가 낮은 항목은 결론에서 차이의 방향만 쓰거나 검정에서 뺐습니다(`analysis/reliability.csv`).
5. **통계 비교**: 범주형 항목에는 카이제곱 검정과 편향을 보정한 크래머의 V를, 계량 지표에는 맨-휘트니 검정을 적용했고, 여러 항목을 한꺼번에 검정한 결과는 벤야미니-호흐베르크 방법으로 보정했습니다(`analysis/assoc_corrected.csv`, `analysis/numeric_tests.csv`).
6. **독립 검증**: 보고서를 쓴 뒤 하위 에이전트 2개가 따로 검증했습니다.
   - 수치와 문장 검증: 보고서에 나온 모든 수치를 데이터에서 다시 계산하고, 한국어 문장 규칙과 논리적 일관성을 확인했습니다.
   - 이미지 대조 검증: 보고서가 특정 호를 묘사한 문장을 원본 이미지와 대조하고, 표본 12장의 핵심 10개 항목을 다시 판정했습니다(일치율 90%).
   - 검증에서 확인된 코딩 오류를 고치고(`analysis/audit_changes.json`, 고치기 전 기록은 `analysis/coding_before_audit.jsonl`), 모든 수치를 다시 계산했습니다.

하위 에이전트에게 준 지시문과 보고는 [`agents/01`~`04`](../agents/README.md)에 있습니다.

## 주요 결과

보고서 요약을 옮깁니다. 두 잡지는 같은 주제를 다루지만 표지를 만드는 방식은 거의 반대입니다.

- **틀**: 매경은 38장 모두 주황 테두리와 고정 칸(보조 커버라인 칸, 하단 정보 띠)을 씁니다. 한경은 파란 제호 블록만 고정하고 바코드 위치까지 표지마다 옮깁니다.
- **이미지**: 매경은 개념 은유형이 58%, 중앙 오브젝트 배치가 74%이고, 거대한 사물 앞에 작은 사람을 세우는 모티프가 29%입니다. 한경은 풀블리드가 49%, 사실적 3D·CG가 41%(3분기에는 58%), 실존 인물 명단이 16%입니다.
- **색**: 색채감 중앙값은 한경 71, 매경 48입니다. 매경의 표제는 100% 검정 또는 흰색이고, 한경의 표제는 54%가 노랑이나 금색입니다.
- **표제**: 한경 표제의 68%에 그림자나 외곽선 같은 효과가 있고 68%가 부제를 달지만, 매경은 효과가 0%, 부제가 3%입니다.
- **어조**: 매경은 경고·위기형 표제가 39%(3분기에는 62%)이고, 한경은 기회·낙관형이 46%입니다.
- **가장 큰 차이**: 잡지와 연관도가 가장 높은 5개 항목이 모두 표제의 색, 효과, 강조, 부제와 포인트 색의 쓰임이었고, 주제 분포는 두 잡지 사이에 유의한 차이가 없었습니다(p=0.58).

이 결과 가운데 고정된 틀, 표제의 3단 위계, 은유 그림 한 개, 호마다 바뀌는 배색은 3단계에서 브리핑 표지를 설계할 때 근거로 썼습니다([03_잡지형_표지_모듈.md](03_잡지형_표지_모듈.md)).

### 문서를 저장소로 옮길 때 고친 점

- 보고서 첫머리에 있던 작성자 표시(사용자 이름)는 공개 저장소에 개인 정보를 남기지 않으려고 날짜만 남기고 지웠습니다.
- 문서 안의 차트는 Markdown으로 내보내면 빠지므로, 같은 차트의 렌더링 이미지를 `report/charts/`에 넣고 원래 자리에 연결했습니다.
- 표지별 코딩 탭은 문서에서 내보낸 내용을 그대로 옮기되, 온라인 문서에서 글자가 깨진 두 곳을 원래 데이터(`coding.jsonl`)에 맞춰 고쳤습니다. 제1583호의 '캉 경제학'은 '캥 경제학'으로, 제1589호의 'K컳처'는 'K컬처'로 고쳤습니다. 온라인 문서에는 아직 깨진 글자가 남아 있습니다.
- 같은 탭에 있던 표지 모음 이미지 2장은 표지 저작권 때문에 넣지 않고 설명 문구로 바꿨습니다.

## 넣지 않은 것

표지 원본 75장, 분석용으로 잘라 낸 표지(`analysis/single/`, `analysis/view/`), 잡지별 표지 모음 이미지(`hk_contact.jpg`, `mk_contact.jpg`), 확대해서 본 부분 이미지는 넣지 않았습니다. 모두 잡지사에 권리가 있는 표지 이미지이기 때문입니다. 그래서 `analysis/metrics.py` 같은 스크립트는 표지 이미지를 따로 준비해야 다시 실행할 수 있습니다.
