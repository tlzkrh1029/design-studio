이 폴더에는 미국 섹터 모니터링 화면 작업 중에 사용자가 제공한 UI 이미지 2장(두 가지 형태)을 둡니다. 두 이미지는 사용자가 블룸버그 터미널과 비슷한 스타일로 직접 만든 것이며, 실제 블룸버그 터미널 화면이 아닙니다.
