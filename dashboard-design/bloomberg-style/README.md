# bloomberg-style: 블룸버그 터미널 같은 스타일의 UI 이미지

이 폴더에는 사용자가 블룸버그 터미널과 비슷한 스타일로 만든 화면 두 가지의 캡처를 둡니다. 두 화면 모두 이 작업에서 Claude 아티팩트로 만든 것이며, 실제 블룸버그 터미널 화면이 아닙니다. 사용자는 2026년 10월 2일에 이 두 형태를 블룸버그 터미널 같은 스타일의 예로 제공했습니다.

블룸버그 터미널 스타일은 이 작업의 여러 디자인 스타일 가운데 하나의 사례이며, 기준선이 아닙니다.

| 파일 | 화면 | 내용 |
| --- | --- | --- |
| [01-sector-rotation-terminal.png](01-sector-rotation-terminal.png) | 섹터 전환 터미널(SRM) | 관찰 대상 ETF 23개의 SPY 대비 상대수익률 백분위(1주~12개월) 히트맵, QQQ·SPY 대비 12주 가격 비율선, RRG 국면, 신호를 한 행에 보여 줍니다. 오른쪽에는 고른 ETF의 구성종목 상위 10개 패널과 행 형태를 읽는 법이 있습니다. 화면 아래쪽 시각 표시는 2026-10-02 17:01 KST입니다. |
| [02-breakout-map-v6.png](02-breakout-map-v6.png) | 돌파 지도(BKM) 시안 v6 | ETF 28개 블록마다 구성종목 상위 10개의 20일 고점 돌파와 저점 이탈을 작은 차트 격자(칸 274개)로 보여 줍니다. 위쪽에는 돌파한 칸의 비율, 돌파 비율이 높은 블록, 알림 조건 미리보기(초안)가 있고, 오른쪽에는 종목 상세 패널, 아래쪽에는 판정 근거가 있습니다. |

- 원본 아티팩트는 섹터 전환 터미널 https://claude.ai/artifact/6591K5Cr3HAFUAKMXav4in 과 돌파 지도 https://claude.ai/artifact/AMAB2TMoSxwXPuLPWjtjGB 입니다. 소유자만 열 수 있는 비공개 링크입니다.
- 섹터 전환 터미널은 원본 HTML을 [../drafts/sector-rotation-terminal/](../drafts/sector-rotation-terminal/index.html)로 내보냈습니다(2026-10-03). 돌파 지도(시안 v6)는 사용자가 내보내지 않기로 해서 이 캡처만 있습니다.
- 01 캡처의 상태 표시줄 아래에 보이는 흰 문장 조각('…인 섹터가 거기에 있으면 이탈 조건을 점검합니다.')은 페이지가 그린 것이 아닙니다. 내보낸 원본을 같은 크기로 렌더링하면 나타나지 않으며, 이 문장은 숨겨진 도움말 탭에만 있습니다(2026-10-03 확인).
- 두 화면의 히트맵 수치, 비율선, RRG 국면, 신호, 가격은 예시 데이터입니다. 구성종목과 비중은 stockanalysis.com의 실제 데이터이고, 상장 점은 2026-09-27에 수집한 거래소 목록과 대조한 값입니다. 자세한 내용은 각 화면 아래쪽의 데이터 설명에 있습니다.
- 저장소에 올리면서, 두 캡처의 데이터 설명 문구에 들어 있던 비공개 저장소 이름은 회색 막대로 가렸습니다. 그 밖의 부분은 받은 그대로입니다.
