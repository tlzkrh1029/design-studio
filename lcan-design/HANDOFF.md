# 인계 문서: lcan-design 작업

이 문서는 외부 UI 요소를 작업별 스타일에 맞게 고치는 작업을 다른 AI(ChatGPT 등)나 사람이 이어받을 때 가장 먼저 읽는 문서입니다. 기준 시각은 2026년 10월 28일(한국 시간)입니다. 일하면서 지킬 규칙은 같은 폴더의 [AGENTS.md](AGENTS.md)와 저장소 맨 위의 [AGENTS.md](../AGENTS.md), [디자인_원칙.md](../디자인_원칙.md)에 있습니다.

## 0. 이 작업의 목적

[Lucian UX/UI Prompt](https://lucianlabs.dev/uxui-prompt/)는 바로 눌러 볼 수 있는 UI 요소 400개를 MIT 라이선스로 공개한 갤러리입니다. 이 작업은 그 가운데 실제 화면에 필요한 요소만 골라 와서, design-studio의 세 작업이 각자의 스타일과 디자인 원칙에 맞게 쓸 수 있도록 고쳐 두는 것을 목표로 합니다.

고친 요소는 이 폴더에 둡니다. GPT는 claude.ai 링크를 열 수 없으므로, 자료가 저장소에 있어야 Claude와 GPT가 같은 파일을 보고 같은 결과를 낼 수 있습니다. 이 폴더의 내용은 원작자와 관계가 없는 사본입니다.

## 1. 지금 상태

- 폴더 구조와 규칙을 정했습니다([README.md](README.md), [AGENTS.md](AGENTS.md), 이 문서).
- 원본을 고정했습니다. lucian-uxui-prompt 커밋 `7e339fa`의 LICENSE와 tokens.css(한국어판)를 `upstream/lucian-uxui-prompt/`에 그대로 두었습니다.
- 베이지 스타일의 테마 파일 초안 [artifact-design/lcan-theme.css](../artifact-design/lcan-theme.css)를 만들었습니다. artifact-design/HANDOFF.md 2절에 적힌 값만 넣었고, 나머지 토큰은 첫 실험에서 정합니다.
- 채택한 요소는 아직 없습니다. `base.css`, `drafts/`, `elements/`, `prompts/`, `tools/`도 아직 없습니다.

## 2. 원본에 대해 확인한 사실

2026년 10월 28일에 원본 커밋 `7e339fa`를 기준으로 확인한 값입니다.

| 항목 | 확인한 내용 |
| --- | --- |
| 구성 | 요소 400개(인터페이스 001~200, 애니메이션 201~400)이고, 분류는 27개입니다. 요소 하나가 HTML 파일 하나이며, 외부 라이브러리 없이 동작합니다. 원문은 한국어이고, 영어판은 번역 목록으로 만듭니다. |
| 가져가는 길 | 갤러리의 '프롬프트 복사'(요소 코드와 10단계 이식 지시문), 코드 파일 받기, 에이전트 스킬(lucian-uxui: 목록을 검색하고 고른 요소만 받음)이 있습니다. |
| 테마 구조 | 색은 `--ux-*` 토큰으로 정의합니다. 다크 모드는 `prefers-color-scheme`, `:root:not([data-theme="light"])`, `:root[data-theme="dark"]`로 정의하며, Claude 아티팩트가 요구하는 테마 구조와 같습니다. |
| 토큰이 다루지 않는 값 | 모서리 값이 128가지이고, 30px만 해도 170곳에 쓰입니다. 700보다 굵은 글자(800, 850, 900)를 쓰는 요소가 294개이고, 흰색과 검은색이 아닌 색을 CSS에 직접 적은 요소가 242개입니다. |
| 명암비 | 작은 글자에 쓰는 `--ux-ink-3`은 라이트 #8E8A97이 바탕과 2.73~3.37:1, 다크가 3.56~3.72:1입니다. 적어도 206개 요소가 18px보다 작은 글자에 이 색을 씁니다. 라이트의 `--ux-accent-2`, `--ux-mint`, `--ux-warn`, `--ux-danger`도 글자로 쓰면 4.5:1에 못 미칩니다. |
| 오르내림 색 | 내림, 손실, 매도 호가는 `--ux-danger`(빨강)이고, 매수 호가는 `--ux-mint`(초록)입니다(096, 098, 158, 172번). |
| 화면 폭 | 루트에 고정 폭을 준 요소도 폭이 모두 375px 이하이고, 94개 요소는 폭이 컨테이너를 따릅니다. |
| 글꼴 | 원본은 Pretendard를 전제로 하지만, tokens.css에는 글꼴을 불러오는 코드가 없습니다. |
| 바뀌는 속도 | 2026-10-12에 요소 200개로 처음 공개했고, 10-16에 400개로 늘리면서 기존 요소 7개(005, 116, 170, 177, 186, 191, 197)를 다시 작성했습니다. |
| 빌드 검사 | `src/build.mjs`는 머리 주석, 분류, 접두사, `@property` 이름, 영어판에 남은 한글을 검사합니다. 하지만 색을 토큰으로만 쓰는지는 검사하지 않습니다. 스킬이 읽는 `api/v1/`을 만드는 스크립트는 공개 저장소에 없습니다. |
| 접속 | Claude 작업 환경에서 lucianlabs.dev에는 접속되지 않았고, GitHub 사본(raw.githubusercontent.com)에는 접속되었습니다. 스킬은 첫 주소가 막히면 GitHub 사본으로 넘어가도록 작성되어 있습니다. 다만 스킬을 직접 실행해 보지는 못했습니다. |
| 이름 | 원작자는 lucian-icons 저장소의 [TRADEMARKS.md](https://github.com/Seokwoooo/lucian-icons/blob/main/TRADEMARKS.md)에서 'Lucian'과 'lucianLabs'가 프로젝트와 소유자를 나타내는 이름이며, MIT 라이선스가 상표 권리를 주지 않는다고 밝혔습니다. 원작자의 공개 저장소는 16개이고(사용자가 10/28에 캡처로 보여 줌), 그 가운데 다섯 개에 `lucian-` 접두사를 씁니다. |

## 4. 지금까지의 결정

1. 저장소 구조는 안 3입니다. 요소는 `lcan-design/`에 두고, 테마 파일은 각 작업 폴더에서 그 스타일을 정의한 곳 바로 옆에 둡니다(사용자 결정, 2026-10-28).
2. 폴더 이름은 `lcan-design`입니다(사용자 결정, 2026-10-28).
3. 테마 파일 이름은 `lcan-theme.css`입니다. 폴더 이름에 맞춰 Claude가 정했습니다. `lc-design`을 논의할 때 '폴더와 짝이 되는 이름'으로 제안한 방식을 따른 것이며, 사용자가 따로 확인하지는 않았습니다.
4. 아래 규칙은 Claude가 구조를 제안하거나 이 폴더를 만들면서 정했고, 사용자가 따로 확인하지는 않았습니다. 사용자가 바꿀 수 있습니다.
   - 원본은 커밋 `7e339fa`에 고정하고, 요소 원본은 들이기로 정한 것만 `upstream/`에 둡니다.
   - 이 폴더에는 같은 원작자가 공개한 자료만 둡니다.
   - 새로 더하는 토큰에는 `--lcan-` 접두사를 붙입니다.
   - 원작자의 스킬은 후보를 찾는 데만 쓰고, 요소를 쓸 때는 `elements/`의 고친 판을 씁니다.
